# 英検1級 語彙リスト(日本語訳つき)

- `eiken1_vocab_ver7.1.xlsx` : 語彙リスト本体(単語シートに日本語訳列を追加、各シートに「覚えた」列)
- `index.html` : ブラウザで検索・閲覧できるビューア(GitHub Pagesで公開可能)

## 注意
- 元の語彙リストの配布条件を確認してから公開してください。
- 日本語訳はAI(Claude)が付けたもので、誤りが含まれる可能性があります。
- ビューアの「覚えた」記録は、そのブラウザ内(localStorage)に保存されます。端末間の移行は「バックアップ・移行」のコードを使ってください。
